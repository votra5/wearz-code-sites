Fonctionnalités

Tout ce qu'il faut pour écrire et tester une page, sans jongler entre les apps.

Éditeur HTML coloré

Coloration syntaxique en direct pour repérer balises, attributs et chaînes d'un coup d'œil.

Aperçu instantané

Un clic sur « Exécuter » ouvre ta page dans un onglet de prévisualisation intégré.

Terminal intégré

Une vraie invite de commandes (cmd ou bash) directement dans l'application.

Console de débogage

Erreurs Python et erreurs JavaScript de la page prévisualisée, classées et colorées.

Connexion sécurisée

Mot de passe hashé localement (jamais stocké en clair). Connexion par nom d'utilisateur, avec bouton pour afficher le mot de passe.

Se souvenir de moi

Une fois connecté, saute l'écran de connexion au prochain lancement.

Installation

Sur le Bureau en quatre étapes.

1

Télécharger l'archive

Récupère wearz-code.zip, il contient l'application et le script d'installation.

2

Extraire le dossier

Décompresse l'archive n'importe où sur ton ordinateur.

3

Lancer l'installeur

install.py installe les dépendances Python et copie l'app dans ton dossier utilisateur.

4

Ouvrir depuis le Bureau

Un raccourci « Wearz Code » apparaît sur ton Bureau, prêt à être lancé d'un double-clic.

# 1. Extraire puis se placer dans le dossier
$ cd wearz-code
# 2. Lancer l'installation
$ python install.py
# 3. Lancer l'application manuellement (optionnel)
$ python app.py

Prêt à coder dans une seule fenêtre ?

Gratuit, fonctionne hors ligne, tes identifiants restent sur ta machine.
